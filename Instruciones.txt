    sudo apt install python3
    sudo apt install golang-go
    #Porfavor crea un ambiente de anaconda, para instalar las dependencias necesarias
    #Ya con el ambiente levantado ejecute los siguientes comandos
        pip install python3-tk <== para tkinter 

Paso 1.2, procure ver si tiene todas las dependencias o servicios necesarios

    1. anaconda3 para tener ambientes de python
    2. docker para el contenedor

Paso 2, Correr front y back con los siguientes comandos
    # Cada comando se debe de ejecutar en terminales distinatas para que de verdad funcione

    cd dir-carp-proyecto/back ===> go run main.go
    cd dir-carp-proyecto/front ===> python3 master.py
    



Paso 1: Levantar la Infraestructura (Base de Datos en Docker)

    cd dir-carp-proyecto ===> docker-compose up -d  <== si no se ha iniciado nunca el contendor
    cd dir-carp-proyecto ===> docker compose start <== si ya exite el contenedor 

Paso 2: Ejecución del sistema completo (3 Terminales)

    Terminal DB: docker-compose up -d
    Terminal Back (Go): cd back && go run main.go 
    Terminal Front (Python): cd front && python3 master.py
